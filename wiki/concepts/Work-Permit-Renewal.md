# Work Permit Renewal

## Definition
Renew an existing helper's Work Permit before it expires. Also called "Work Permit Enable". MOM generates a Renewal Notification roughly 8 weeks before the WP expiry date, and this notification is essential to apply. Renewal keeps a trusted helper in place and avoids the processing gaps that create legal complications. (src: raw/minghwee-services-knowledge-base-v1.md §3. Work Permit Renewal · 2026-09-08)

## Why it matters here
It is time-boxed by two independent MOM clocks — the ~8-week Renewal Notification and a short-lived e-authorisation link — so the failure mode is missing a window, not doing a step wrong. The bot/staff must start early and not let the authorisation link lapse.

## Full process
(src: raw/minghwee-services-knowledge-base-v1.md §3. Work Permit Renewal · 2026-09-08)

1. Employer enquires to renew; create/attach the account and input data. MOM sends the Renewal Notification (~8 weeks before expiry) — obtain a copy.
2. Request the materials: Renewal Notification, employer IC copy, helper passport, new salary and number of rest days.
3. Send the e-authorisation request; employer authorises within the 1-week link validity (else it expires). Once authorised, a 2-week window to complete.
4. Employer signs the Renewal Declaration form.
5. Purchase FDW insurance (ideally before 5pm so it processes overnight); next day proceed with the renewal transaction.
6. Once insurance is processed, input the new policy number and expiry into the signed Renewal Declaration.
7. Upload the signed declaration to the MOM website and submit; a Temporary Work Permit and renewal confirmation are auto-generated on submission.
8. Forward the renewal confirmation to the employer to confirm completion. Coordinate the 6-monthly medical exam as required.

## Documents
Requested: employer's NRIC copy, Renewal Notice/Notification from MOM, worker's new salary, number of rest days, helper's passport, e-authorisation via the MOM site. Prepared: Renewal Declaration form (e-signed by employer). See [[Forms-and-documents-register]]. (src: raw/minghwee-services-knowledge-base-v1.md §3. Work Permit Renewal · 2026-09-08)

## Gotchas
- Two clocks, both easy to miss: the ~8-week Renewal Notification and the 1-week e-authorisation link. Start 60+ days out.
- Insurance timing is deliberate — buy before 5pm so it clears overnight, otherwise the next-day transaction stalls.
- New salary and rest days feed the renewal declaration; both are volatile employer inputs, not defaults.
